## New Cursor plan marks in the menu bar

- The Cursor item in the menu bar now shows the marks of everything its plan covers, xAI, Grok, Cursor and Grok Bot, in a small centered row above the percentage. They replace the cube and the "Cursor" name.
- The marks are drawn as vectors, so they stay sharp on every display, and follow light and dark menu bars.

## Update

Use **Check for Updates** in Usagebar, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.10.3...v1.10.4)
