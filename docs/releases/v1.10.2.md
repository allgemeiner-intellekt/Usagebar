## Grok Bot counts as Cursor

- Show Cursor usage while Grok Bot is in front. Grok Bot is Cursor's agent app and draws on the same subscription; before, its name made it select XAI.
- When Grok Bot is signed in to the same Cursor account, the menu calls the section **Cursor & Grok Bot**. Usagebar compares hashed account identifiers only and never reads Grok Bot's tokens.

## Update

Use **Check for Updates** in Usagebar, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
