## A new usage panel

- Right-click Usagebar in the menu bar to open a panel with every provider: its mark, plan, a meter for each limit, and when it resets. It replaces the menu, with the same design as the upcoming Windows version.
- Click a provider's card to show it in the menu bar. The refresh button and "Updated" time sit at the top.
- Display, Show Icon, Launch at Login, sign-out, and update settings are under the panel's **⋯** button. When an update is available, the panel's footer offers it.

## Update

Use **Check for Updates** in Usagebar (now under **⋯**), or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
