## Brand marks in the menu

- The menu's provider headers now show each provider's mark: the Claude spark next to "Claude", the Codex logo, Cursor's four plan marks (xAI, Grok, Cursor and Grok Bot), and ZCode's Z mark with "Code".
- Headers are drawn at full contrast. Before, they were dimmed like unavailable menu items.

## Update

Use **Check for Updates** in Usagebar, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.10.6...v1.10.7)
